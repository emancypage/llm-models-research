# Public-copy coverage

The public snapshot keeps every original Bielik report data file, including the first compatibility measurement, the failed isolated-form validation, all layer-level statistics and token projections, the successful paired-form run, contribution data, baseline and post-edit predictions, checkpoint verification, all safety aggregates, all six per-item refusal/invalid flag arrays, and telemetry. Metrics, seeds, revision hashes, durations, model configuration and uncertainty are retained. Private hardware identity/capacity, session identifiers and private paths are removed or replaced with portable equivalents. Historical hashes still identify the original private artifacts, not byte-for-byte public copies; privacy edits change their bytes. Native schema acceptance recorded in the historical report applies to the original records; sanitized copies have not been accepted by the original schema validators.

The initial isolated-form attempt failed with `lexical_confound` and produced no edited checkpoint. The first two paired-form export attempts failed on custom-concept metadata before the corrected run succeeded. No model weights are included.

Benign compatibility, tense and Belebele code and question data are kept. Hardcoded working directories are now configurable with `BIELIK_WORK_DIR` (default `work`). The Compose file is a portable template rather than the private deployment configuration: users supply an image and data directory; private image names, mounts, secret-file locations and credential wiring are omitted. The template disables telemetry by default. Historical scripts that require telemetry logging need a separately reviewed configuration to run fully; no fresh full model experiment was run during publication preparation. Corpus, model cache, dependencies and the pinned OBLITERATUS checkout must be supplied by the reader.

The live harmful-battery runner, live repeat execution and live Polish re-generation path are replaced by offline inspection code. [safety_battery.py](../../experiments/2026-11-21-bielik-11b-polish-tense/safety_battery.py) validates the published boolean flags and counts; [safety_repeats.py](../../experiments/2026-11-21-bielik-11b-polish-tense/safety_repeats.py) retains the historical summary calculation over those flags and requires the pinned OBLITERATUS statistics module; [safety_polish_check.py](../../experiments/2026-11-21-bielik-11b-polish-tense/safety_polish_check.py) preserves the exploratory Polish opening detector and harmless refusal controls. [run_safety_repeats.sh](../../experiments/2026-11-21-bielik-11b-polish-tense/run_safety_repeats.sh) now calls only the offline summarizer. No harmful prompts or model answers are shipped. Aggregate measurements and original methodology remain available in the report data, including generation length, seed, batch size, detector identity and prompt-set hashes.

Refusal detection is not a harmfulness score. The native detector missed the three tested Polish equivalents, while the exploratory opening rule found zero additional refusals in the measured 48-token runs. This limited phrase check does not establish Polish-language coverage. `PASS` at 48 tokens and `INCONCLUSIVE` at 128 tokens concern the declared refusal-rate margin; the wider collateral check remained `INCOMPLETE`. The six deterministic repeats use the same 320 independent questions and do not increase sample size. Grammar was the intervention target; harmful assistance was not established by these statistics.

No third-party correspondence, credentials, private endpoints, host identifiers, private hardware details or local user paths are included in this scope.
